# Learn From Mistakes Skill

This skill ensures that the AI agent actively learns from user corrections and avoids repeating engineering mistakes.

## Core Rules

1. **No Shortcuts on Firewalls**
2. **Live Verification Only**
3. **Active Learning from Corrections**
4. **Keep Architectures Simple (Common Sense)**
5. **Do Not Offload Automation to the User (Common Sense)**
6. **Explain Repeated Permissions and Problems Clearly (Common Sense)**
7. **Explicit User Authorization (Common Sense)**
8. **Avoid Unnecessary Custom Code Nodes (Common Sense)**
9. **Do Not Use LLMs for Simple Deterministic Tasks (Common Sense)**
10. **Auditor Must Verify Architecture, Not Just Status (Common Sense)**
11. **Verify Tool Capabilities BEFORE Use (Common Sense)**
12. **Verify Tool Existence and Access BEFORE Recommending (Common Sense)**
